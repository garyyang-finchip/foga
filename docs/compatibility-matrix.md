# Compatibility matrix

Compatibility is declared per ERC in three parts: the specification version FOGA follows, the role FOGA takes, and the run evidence that proves it. An interface that merely exists is never counted as a pass. Verdicts use the doctor's vocabulary: Pass / Fail / Unknown / Not tested / Not applicable.

Status key for the evidence column: **L1–L4** = doctor layers 1–4 pass on a locally deployed world (`deployments/local.doctor.example.json`); **L5** = semantic validation through the genesis scenario (`deployments/local.genesis.example.json`, T0–T9; `foga doctor --genesis` attributes its checks per standard, all eleven Pass in `deployments/local.doctor.example.json`).
