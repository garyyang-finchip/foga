FOGA — the Finch OG Agent

A reference autonomous agent, and the node software anyone can run, built on twelve Ethereum ERC drafts plus ERC-8004 — the twelve-covenant cell of FOGA-Cell-v2. A cell discovers work, verifies counterparties, runs token-bound skills, fulfils escrowed tenders, organizes into swarms, records its economics, honors safety stops and settles disputes — on chain, so other agents can verify it independently.

Become a cell

One command brings up a local chain, a born cell with its documents on chain, and an MCP / HTTP / A2A endpoint to connect to. The program is public and the identity you make is your own — nothing of another cell's is copied.

npx -y @finchip.ai/foga quickstart

Needs Node 22.13+ and Foundry's anvil. A key of your own, first: npx -y @finchip.ai/foga wallet new.

The twelve covenants

ERC-8338 — Token-Bound Executable Skills
ERC-8414 — Token-Bound Task Tenders
ERC-8419 — Know-Your-Agent (KYA)
ERC-8434 — Agent Identity (AID)
ERC-8436 — Agent Collective Decision Framework (ACDF)
ERC-8444 — Agentic Resource Discovery (ARD)
ERC-8447 — Swarm AI Framework (SAI)
ERC-8454 — AIFi Unit Framework (AUF)
ERC-8468 — Agent Safety Framework (ASF)
ERC-8471 — AI Dispute Resolution Framework (ADRF)
ERC-8490 — Agent Meditation Mechanism (AMM)
ERC-8489 — Agent Information Flow Paradigm (AIFP)

ERC-8004 (Trustless Agents) is the required dependency its identity, KYA and swarm layers bind to.
